01–18 — The Full Roadmap

Every step.
Factory to market.

Ordered by dependency. Can't do step 5 before step 2. Each step is a standalone unit of work.

```
1
Create panda-colors repo Foundation Day 1 · 2–3 hrs

New repo under PandaTheme/panda-colors. Initialize TypeScript project with pnpm. This is the single source of truth for all colors going forward. Everything else depends on this existing.

pnpm init tsconfig.json src/tokens.ts with OKLCH values src/convert.ts (oklch→hex) README.md
2
Define all tokens + semantic roles Foundation Day 1–2 · 3–4 hrs

Write src/tokens.ts with every color in OKLCH. Write src/semantic.ts mapping tokens to syntax roles (keyword, string, function, type, etc.). Write src/wcag.ts that auto-checks contrast ratios at build time — if any token fails AA, the build fails.

10 base tokens in OKLCH semantic role mapping WCAG AA build check Color Semantics doc
3
Build variants system Foundation Day 2 · 2 hrs

Write src/variants.ts — generates all 8 theme variants by adjusting L and C in OKLCH. This is the code that makes Panda Pro possible without designing 8 themes from scratch. Midnight, Mist, Bamboo, Sakura, Abyss, Ember all come from this one file.

adjustL() helper 3 free variants 5 Pro variants variant preview generator
4
Build generators — all output formats Foundation Day 3–5 · 1 day

Write generators/ folder. Each file takes PandaTokens and outputs a specific format. pnpm build runs all generators and drops results in dist/. This is the automation that makes every port trivial to maintain.

generators/vscode.ts generators/css.ts generators/json.ts (W3C DTCG) generators/terminal.ts generators/figma.ts build.ts entrypoint
5
Publish @pandatheme/colors to npm Foundation Day 5 · 1 hr

Publish the package. Version 1.0.0. This is the moment the ecosystem becomes programmable. Any developer or port maintainer can now import Panda tokens directly. Set up GitHub Actions to auto-publish on version tag.

npm publish GitHub Actions CI CHANGELOG.md MIT license
6
Rebuild VS Code theme from panda-colors Ports Week 2 · 4–6 hrs

Replace the handcoded JSON in panda-syntax-vscode with generated output from panda-colors. Add semantic token support (VS Code 1.43+). Fix TypeScript, Rust, Go, Python, Prisma, MDX token coverage. Transfer repo from siamak/ to PandaTheme/ org. Bump to v3.0.

Transfer repo to org Semantic tokens API Rust / Go / Python fix Publish v3.0.0 GitHub Sponsors enabled
7
Port to Cursor editor Ports Week 2 · 2 hrs

Cursor uses VS Code theme format. The generator already outputs this. Create PandaTheme/panda-syntax-cursor, publish to Cursor Marketplace. Fastest new audience. Cursor users are exactly the aesthetic-forward developer Panda targets.

New repo in org Cursor Marketplace publish README with screenshots
8
Port to Zed editor Ports Week 2 · 2–3 hrs

Write generators/zed.ts. Zed uses JSON with slightly different schema. Publish to Zed extension registry. Zed is growing fast — Dracula has it, Panda doesn't yet. Fix this.

generators/zed.ts Zed extension manifest Zed registry publish
9
Terminal ecosystem ports Ports Week 3 · 3–4 hrs

One generator, multiple outputs. generators/terminal.ts outputs Ghostty, WezTerm (Lua), Alacritty (TOML), iTerm2 (XML), Kitty (conf). All in one build pass. Create individual repos in org or one panda-terminal-themes monorepo.

Ghostty WezTerm Alacritty iTerm2 update Kitty
10
panda.dev — website launch Brand Week 3–4 · 1 week

Next.js site. Homepage with live code preview, color palette, port directory. /spec page with full color spec. /open page with live metrics (npm downloads, GitHub stars, installs). Email signup powered by Resend. This is the conversion surface for Pro.

Homepage Live code preview Port directory /spec page /open metrics Email signup (Resend) OG images
11
GitHub org cleanup + .github profile Brand Week 3 · 2 hrs

Create .github repo in PandaTheme org — this powers the org profile page at github.com/PandaTheme. Add profile README, contributing guide, port template. Archive dead repos. Pin the 6 best repos. Add topics/tags to each repo for discoverability.

.github/profile/README.md CONTRIBUTING.md Port template repo Archive old forks Pin best 6 repos
12
Programmatic wallpapers Brand Week 4 · 3–4 hrs

Generate wallpapers using Satori or Canvas — SVG→PNG pipeline driven by panda-colors tokens. One wallpaper design, all 8 variants, all resolutions (1080p, 1440p, 4K, 5K, ultrawide, phone). Free base wallpapers in repo. Animated / seasonal wallpapers for Pro.

Satori SVG generator All 8 variants 1080p–5K + phone sizes Free release in GitHub Animated for Pro pack
13
Assemble Panda Pro package Pro Month 2 · 1 week

Package everything into the Pro zip. 5 Pro variants for every supported app, wallpapers, icon pack, Figma tokens, font curation guide. Well-organized folder structure. Every file named consistently. Quality feels premium even before opening.

5 Pro variant themes × all apps Wallpapers all sizes macOS icon pack Figma token file Font curation PDF Setup guide PDF ZIP organized cleanly
14
Set up Gumroad / Lemon Squeezy store Pro Month 2 · 2 hrs

Create product page. Price at $14. Write compelling copy — lead with "Everything Dracula Pro has, at 1/5th the price." Enable purchasing power parity for 160+ countries. Set up webhook to deliver zip on purchase. No DRM, no activation — trust your customers.

Gumroad product page $14 price + PPP Product screenshots Purchase delivery webhook Team license option ($49)
15
Launch — announcement campaign Pro Month 2 · Launch day

Announce on X/Twitter, post on r/vscode and r/unixporn, submit to HackerNews Show HN, post on DEV.to. Email the list you've been building. Update VS Code Marketplace description with Pro link. The story: "1.2M installs, back from the dead, and now there's Pro."

X/Twitter thread Reddit r/vscode + r/unixporn HN Show HN post DEV.to article Email newsletter #1 Marketplace description update
16
Figma Community kit Growth Month 3 · 4 hrs

Publish Panda color tokens as a Figma Community file. Free base (10 colors, dark only). Pro version includes all 8 variants, typography scale, component tokens, icon set. Figma Community has a completely different audience from VS Code — designers who will bring Panda into their projects.

Figma Community file Color styles Token variables Pro variants in paid
17
JetBrains official plugin Growth Month 3 · 1 day

Take ownership of the JetBrains port. The existing panda-syntax-intellij in the org is a community fork and inconsistent. Write generators/jetbrains.ts, publish an official plugin to JetBrains Marketplace. This covers IntelliJ, WebStorm, PyCharm, GoLand, DataGrip — one plugin, millions of users.

generators/jetbrains.ts JetBrains Marketplace publish All IDE variants UI + Editor theme
18
Merch + community flywheel Growth Month 4+ · ongoing

Start merch with zero inventory risk — Printful or Printify print-on-demand. Sticker pack first (highest margin, easiest to ship). Newsletter cadence: 1 email/month with a port update, dev environment tip, behind-the-scenes. Discord server. GitHub Discussions. Let the community build ports you don't have to maintain.

Sticker pack (Printful) Monthly newsletter Discord server GitHub Discussions Community port bounties Raycast / Alfred / Linear ports
```
